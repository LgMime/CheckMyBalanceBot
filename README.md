### CheckMyBalanceBot

**Для резюме:**
* **Назва:** **Telegram Balance Tracker Bot**
* **Стек:** `C#, .NET, Telegram.Bot, SQLite`
* **Опис:**
  * Telegram bot for logging daily expenses, income, and checking current balance.
  * Implemented interactive inline buttons and step-by-step chat dialogs.
  * Stored transaction history in a local database.
